# Roy Ramdaw & Associates Inc. — Independent Website Concept

Static responsive 9-page website, no npm build required.

## Local preview
`python3 -m http.server 8000` in this folder, then http://localhost:8000.

## Deployment
Vercel framework preset: **Other**. Root directory: `.`; output: `.`.
`gh repo create roy-ramdaw-associates --public --source=. --remote=origin --push`
`npx vercel --prod`
